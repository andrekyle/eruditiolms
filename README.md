# Learning Management System (LMS)

A web-based Learning Management System similar to Moodle that allows creating and managing courses, quizzes, and lessons.

## Features
- User authentication (teachers and students)
- Course management
- Lesson creation and management
- Quiz creation and assessment
- Progress tracking

## Installation

1. Create a virtual environment:
```bash
python -m venv venv
```

2. Activate the virtual environment:
- Windows:
```bash
venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
python app.py
```

## Usage
Visit http://localhost:5000 in your web browser to access the LMS.
